# Sikkerhed for udviklere

Dette repository indeholder kodeeksempler, øvelser og undervisningsmateriale til kurset softwaresikkerhed for udviklere.

Materialet hjælper studerende med at identificere sårbarheder, forklare hvordan usikker kode kan misbruges, og foreslå mere sikre implementeringer. Eksemplerne dækker blandt andet inputvalidering, sikker håndtering af data, adgangskontrol og sårbarheder i flere programmeringssprog.

Materialet er organiseret efter sessioner. Hver session kan indeholde selvstændige snippets, øvelsesbeskrivelser og eventuelle løsningsforslag.

Nogle kodeeksempler er med vilje sårbare. De må derfor kun bruges i et kontrolleret undervisningsmiljø og må ikke anvendes i produktion eller eksponeres på offentlige systemer.
